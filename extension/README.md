# Forge Agent

Editor-native coding agent for VS Code whose agent loop runs on [TrueForge](https://github.com/truefoundry/trueforge).
Inline edit (Ctrl+Alt+E), agent mode panel, budgeted context retrieval with reasons, per-hunk diff review with undo, streaming and safe cancellation, automatic model fallback.

Setup, settings and the full documentation: <https://github.com/positron-nb/starDust_forge>
